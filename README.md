# AIM ZERO · 零点练枪

基于 Godot 4.7.2 与 GDScript 的离线第一人称 3D 训练软件。Windows 便携包解压后直接启动 `AIM-ZERO.exe`。模型、室内场景和音效由项目代码生成，中文字体随程序打包。程序只处理本窗口的输入与本地训练数据，与无畏契约进程独立运行。

## 训练

| 项目 | 机制 |
|---|---|
| 六球速射 | 六靶同时出现，击中即补靶。 |
| 微调定位 | 小靶在上一靶附近刷新，训练短距离修正。 |
| 人形目标爆头 | 分离头部与躯干判定，爆头刷新目标。 |
| 动态跟枪 | 可按住左键连发，独立记录在靶时间占比。 |
| 急停射击 | 横移触发亮靶，减速与停稳过程中按速度和恢复时间模拟散布。 |
| 实战预瞄 | 实体掩体阻挡移动和射线，侧移露出目标。掩体有头线标记。 |
| 极限反应 | 随机亮靶、限时消失，记录命中和漏靶。 |
| 自适应训练 | 根据本地分项成绩排序，每 15 秒切换项目，根据本轮表现调整难度。 |

一键热身按快速定位 2 分钟、爆头 2 分钟、急停 3 分钟、预瞄 3 分钟自动切换。首次进场有准备倒计时，正式训练净时长为 600 秒。Esc 和窗口失焦都能暂停计时。普通专项可选 30、60、90、120 秒。

## 输入、显示与统计

- 灵敏度以每个鼠标计数转动 `灵敏度 × 0.07°` 为基准。默认视野是 16∶9 下水平 103°，其余宽高比保持垂直视野。移动射击系数为训练模拟参数。
- Windows 鼠标捕获由 Godot 处理。原始输入选项使用 `screen_relative` 并关闭事件累积，让每个传到程序的事件直接更新视角。关闭该选项进入合并事件的兼容模式。
- 移动、目标和记分采用 240 Hz 固定步进或该步进的瞬时状态。射击冷却和自动连发使用训练时钟。渲染插值仅用于显示；反应和首次预瞄采样依据实际呈现帧。
- 帧率选项包括 60、120、144、165、180、240、360、480、500、600、1000 帧/秒和无限制。全屏默认关闭垂直同步，刷新率由操作系统与硬件决定。极低画质关闭动态光照、抗锯齿和附加场景装饰。
- 性能监测记录帧间真实耗时。平均帧率和最慢 1% 帧率使用最近约 4 秒数据。最慢 1% 帧率为该组帧平均耗时的倒数，采满 100 帧后显示。
- 命中率为命中数除以发射数。爆头率为人形目标爆头数除以人形命中数。单靶反应时间从首次出现于可见区域到达成命中条件，六球与跟枪没有单靶反应样本。热力图累积开枪时到可见目标的准星角偏差。拉枪分析以当次拉动的初始位置为基准。
- 最近 500 条完整训练保存在 Godot 用户目录内。报告显示同项目最近 20 次有射击样本的命中率。可用设置页的 JSON 备份导入和导出，重复导入按记录 ID 去重。

## 开发与构建

用 Godot 4.7.2 打开项目，按 F6 运行主场景或按 F5 运行项目。安装 4.7.2 官方导出模板后，可执行：

```sh
godot --headless --editor --path . --import
godot --headless --path . --script tests/run.gd
godot --headless --path . -- --smoke-test
mkdir -p build/windows build/web
godot --headless --path . --export-release Windows build/windows/AIM-ZERO.exe
godot --headless --path . --export-release Web build/web/index.html
```

Windows 预设嵌入游戏数据。打包时将 EXE、`使用说明.txt` 及 Godot 与字体许可放入同一 ZIP。仓库附带 GitHub Actions 工作流，每次推送或拉取请求会在 Windows 执行自动化测试、运行导出的 EXE 并上传压缩包。Web 预设使用单线程兼容性渲染。浏览器中的鼠标捕获需要用户手势，存储、帧率和输入受浏览器限制。

## 验证范围

本次构建通过了 44 项核心自动化检查，包括 600 秒热身流程、渲染采样节奏变化下的运动和判定一致性，以及训练备份往返。Windows 导出产物的冒烟检查还覆盖了 8000 个合成鼠标事件的位移累计、射击、暂停、报告和本地写入。合成事件检查只覆盖应用的输入处理路径。

原生 Windows 10/11、500 Hz 及更高刷新率屏幕、稳定 500 FPS、真实 8000 Hz 鼠标回报率与端到端延迟尚未进行硬件验证。GitHub Actions 工作流随源码提供。
